11+ Practice Papers: How to Use Them Effectively

Important: 11+ arrangements vary by school and region. Always check the current admissions and test information published by the school, consortium or local authority you are applying to.

Practice papers can be useful, but simply doing more papers is not automatically better. The most valuable routine is attempt → mark → review → practise → retest.

Start untimed, then add pressure

When a question type is new, learn the method first. Once accuracy is good, introduce a timer. This helps children build speed without learning rushed habits.

Keep an error log

Record the question type, the mistake and the correct method. Useful categories include calculation error, vocabulary gap, misread question, reasoning pattern, time pressure and careless checking.

Use papers as diagnostics

A mock paper is most useful when it tells you what to practise next. A low score in one area is not a label; it is information about the next skill to work on.

Use original material responsibly

Do not assume that an online paper is an official past paper. Check the source and copyright status. Original practice questions can still be valuable when they reproduce the skill and difficulty without copying protected questions.
