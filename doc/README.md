# Homework Magic documentation

This directory contains the operational testing guidance for Homework Magic.

- [Testing](TESTING.md) covers the local test commands and test layers.
- [End-to-end testing](END_TO_END_TESTING.md) covers browser journeys.
- [Test plan](TEST_PLAN.md) defines release-critical coverage.
- [CI/CD](CI_CD.md) describes the validation and deployment gates.
- [Privacy and safety testing](PRIVACY_SAFETY_TESTING.md) covers child-safety, identity and data-handling checks.

Deployment-specific setup remains in [`deploy/`](../deploy/README.md).
